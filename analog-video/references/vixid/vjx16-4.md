# VIXID VJX16-4 — 16-input, 4-track SD video mixer

Device reference: I/O, signal path, per-track processing, presets, menus, specs, and the
errors in the manufacturer's manual. VIXID is defunct.

- MIDI CC map, SysEx protocol, Snapshot Manager and bank format →

## What it is

| Item | Value | Source |
|---|---|---|
| Tracks | 4 real-time tracks, stacked on layers A (front) – D | User Guide pp. 5, 19 [Official] |
| Video inputs | 16: 8 composite (RCA), 8 S-Video (4-pin mini-DIN) | pp. 9, 11, 77 |
| Video outputs | 3 independent outs, each doubled composite + S-Video = 6 jacks | pp. 9, 16, 77 |
| Levels | Composite and Y 1.0 Vp-p · C 0.286 Vp-p · 75 Ω, in and out | p. 77 |
| Processing | 4:2:2 Y Cr Cb, 8-bit, 13.5 MHz (BT.601) | p. 77 |
| Standards | PAL / SECAM / NTSC, one standard for the whole deck | pp. 12, 73 |
| Control | MIDI in/out (5-pin DIN), CC only | pp. 66, 77 |
| Audio | Stereo in, stereo out (copy of in), plus a real-time audio analyser for syncing effects to music | p. 12 |
| USB | Firmware update only | p. 12 |
| Presets | 16 per section × 9 sections, plus 16 whole-track presets | p. 62 |
| Power | 5 V DC 3 A adapter, 15 W | pp. 9, 77 |
| Presets total | Up to 144 (9 sections × 16) | pp. 10, 62 |
| In the box | Mixer, AC adapter, power cord, CD | p. 5 |
| Size / weight | 300 × 350 × 100 mm · 4 kg | p. 77 |

The core is digital SD; the I/O is analog. ⚠️ Nothing in the manual says the 16 inputs are
frame-synchronised, and there is no reference input.

## Handling and power

- **All cables under 3 m** — audio, video, USB, MIDI. [pp. 2, 12]
- **USB: a PC only.** The manual warns that anything else (USB lamp, USB key) risks damage. [p. 12]
- Power-up order: cord to adapter → adapter to mains → mixer switch OFF → adapter into mixer →
  switch ON. Only the supplied adapter; it may run warm. [pp. 2, 12]

## Front-panel navigation

- **Shared controls:** four knobs and a trackball, reassigned by whichever section is active.
  [p. 8]
- **Fine button:** drawn beside the shared controls on every effect diagram, **never explained**
  in the manual.
- **JOG wheel + Enter + Back** drive every drop-down menu (Fx, Motion, Crop, transitions,
  Master). [pp. 33, 71]
- Leave the Master menu by pressing any section's own button (Transition Type, RGB, BCS, Fx,
  Motion, Crop, Keyer Type, Audio Type). [p. 71]

## Inputs are not a matrix

[p. 13 diagram, page image read]

- Each track owns **its own four jacks**: Composite 1, Composite 2, S-Video 3, S-Video 4.
  The rear panel groups them Track 4 … Track 1.
- A source only reaches the track it is plugged into. ⚠️ One camera on two tracks needs an
  external distribution amp.
- Selection: hold **Input**, press a 4×4 matrix button per column (column = track,
  row = input). LCD shows `TrN: InputX - COMP|SVIDEO`.
- The p. 13 prose ("S-Video n°1") counts S-Video jacks from 1; the diagram and LCD number them
  3 and 4. Same jacks.

## Video standard

- Rear selector **P** = PAL/SECAM, **N** = NTSC. **Read at power-up only**; moving it while
  running does nothing. [p. 12]
- In P, outputs are PAL; each input is set PAL or SECAM in Master → Video → Standard. [p. 73]
- Selector on **U** at power-up = firmware update mode. [p. 12]

## Outputs and buses

[pp. 16–18, 72]

- Two buses: **Master 1** and **Master 2**.
- 16 preview points: per track **PreFx · PostFx · Keyer · Out Blend**.
- Each output is set to **Master1, Master2, Preview, or Auto Preview**.
- Auto Preview follows the operator: PostFx of the selected track by default, PreFx of a
  track whose input just changed, Keyer of a track whose keyer is being edited.
- Hold **Out1/2/3** + matrix button = pick that output's preview point.
- Colour bars per output (Master → Video → Colorbars); not retained over power-off. [p. 74]

## Compositing

[pp. 21–24]

| MixMode | Behaviour |
|---|---|
| Compositing (default) | D over background → C → B → A; result on both Master buses |
| Battle 2×2 | Layers A + B → Master 1; C + D → Master 2. **Solo disabled** |

- Top layer's **alpha** and **blend mode** decide each pairing: alpha 0 → the lower layer;
  alpha max → the blend result.
- Blend modes, per track: Normal · Additive · Average · Darken · Lighten · Stamp · Difference ·
  Subtract · Negation · Xor · Red · Green · Blue.
- Blend knob steps through modes live. **Hold + knob** = browse without applying; applies on
  release.
- Layer order: press a matrix button to move one track to that layer (others shift), or hold
  two buttons to swap two tracks. [p. 20]

## Per-track controls

| Control | Behaviour | Source |
|---|---|---|
| Opacity fader | Alpha of the track | p. 25 |
| Mute | Track fully transparent; fader ignored while on. Several allowed | p. 25 |
| Solo | All non-solo tracks transparent. Several allowed. Solo and Mute exclusive per track | p. 25 |
| Gain | 0–255 panel scale: 128 = unity, 255 ≈ ×2 (255/128 = 1.99), 64 = ½, 0 = off | p. 26 |
| Select | Chooses the track the effect sections edit; hold = status on LCD | p. 27 |

**Select status line** (hold Select) [p. 27]: input, gain, blend, and flags for RGB, BCS, Key,
Crp, Fx, Mot. Transition state reads **Wipe** (armed), **Wipe!** (running), **Wiped** (track
now transparent). A `*` after a flag = that effect is linked to audio/BPM extraction.

## Colour

[pp. 28–31]

| Effect | Range (panel) | Neutral |
|---|---|---|
| RGB Balance (gain per channel) | 0–255 | 128 |
| RGB Offset (added per channel) | −255 … 255 | 0 |
| BCS (brightness, contrast, saturation) | 0–255 | 128 |
| Negative, B&W | on / off | off |

## Geometry and motion

One Fx at a time per track; one Motion at a time; Crop separate. [pp. 32–44]

| Fx | Parameters |
|---|---|
| MirrorL / R / U / D, FlipH / V, Rot180 | none |
| Blow (edges smear outward) | L, R, U, D band widths; trackball moves all four |
| Scroll, ScrollWrap, ScrollX, ScrollY, ScrollWrapX, ScrollWrapY | Zoom X/Y 1–63 (default 1); X ±720; Y ±576 PAL / ±480 NTSC |
| Mosaic | Repeats X/Y 1–63 |

| Motion | Parameters |
|---|---|
| Freeze | none |
| SlowMotion | N frozen of P frames |
| Strobe | N visible of P frames, rest transparent |
| Bloc (moving-area block refresh) | Size X/Y 1–7 |

- N 0–127, P 2–127, N ≤ P. [pp. 39–40]
- **Crop / CropCenter**: % per edge; CropCenter keeps L = R and U = D.
- **Bkg. Alpha** decides what crop/scroll leaves behind: off = opaque black, on = transparent
  (the PiP switch). [p. 44]

## Keyers

One per track, independent. [pp. 45–54]

| Type | Keys on |
|---|---|
| ColorKeyer | R, G, B |
| ChromaKeyer | Cr, Cb |
| LumaKeyer | Y |
| R / G / B Mask | One channel of the source used directly as alpha |

- **Tol** widens the selected range; **Tran** softens the edge (useful on compressed sources).
- **Source (In. Track)**: any of the four tracks, PreFx or PostFx. PreFx lets you colour-grade
  without moving the key; PostFx lets grading shape it.
- **Pick**: cursor on the preview output + trackball. With Pick lit the keyer re-samples
  continuously and follows a shifting backdrop; unlight it to hold the last value.
- **Inverse** flips kept/removed.
- **Keyer runs in preview only until On is lit** — safe to build during a show.
- Keyer preview shows two side bands with the selected colour/range.

## Transitions

[pp. 55–59]

- Takes one track from opaque to transparent. **One transition at a time.**
- Types: DrkLum, LgtLum (luma wipes); Lin1–4, Cent1–5, Corn1–4, Mid1–4, Doubl1–4, Quad1–4.
- Auto duration 1–150 frames: 150 / 25 = **6.0 s PAL**, 150 / 30 = **5.0 s NTSC**.
- Auto won't start unless the fader is at an end. Moving the fader overrides an auto
  transition. Direction inverts after each completed auto transition.
- A track made fully transparent by a transition is auto-Muted when you move on to another.

## Audio section

What the manual does say — it never documents the controls themselves:

- Buttons: **Type**, **Link**, **BPM**. [p. 63 figure text]
- Audio or BPM extraction can be **linked to RGB, BCS, Keyer, Crop, Fx or Motion** per track.
  [p. 27]
- Audio Type and Audio Link each have 16 presets and a reset (hold Reset + Type / Link).
  [pp. 60, 62]

## Presets and reset

[pp. 60–65, 76]

- 16 presets for each of: Keyer, Fx, Motion, Crop, RGB, BCS, Transition, Audio Type,
  Audio Link.
- 16 whole-track presets (Keyer, Fx, Motion, Crop, RGB, BCS, Blend, Bkg Alpha, Negative, B&W).
- **Not saved:** keyer In. Track, transition Track.
- Recall: hold section button + matrix button. Save: **Preset**, then section (or Select),
  then matrix button. Survives power-off.
- Reset a section: hold **Reset** + section button. Reset a track: hold **Reset** + Select —
  gain, opacity, Mute and Solo are left alone.
- Factory preset restore: Master → Presets (two confirmations).

## Master menu

[pp. 71–76]

`Presets` · `Video` (Outputs, MixMode, Standard, Colorbars) · `MIDI` (Reset, MIDI In channel
enables 1–5, MIDI Out = **Out** or **Thru**) · `HMI` (LED brightness 1–7 for matrix, red,
green).

- MIDI Out is **either** panel moves (Out) **or** a copy of MIDI In (Thru), never both.
- `#` on the MIDI In screen = data arriving.
